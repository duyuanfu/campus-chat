# 部署说明（给 A：小程序前端负责人）

照着下面做，3 分钟就能在你自己的电脑上把后端跑起来。

## 一、准备环境（只需要装一次）

1. 安装 Python（3.9 及以上版本都行，推荐 3.10 ~ 3.12）
   - 下载地址：https://www.python.org/downloads/
   - ⚠️ Windows 安装时，**一定要勾选「Add Python to PATH」**

装完后，打开终端（PowerShell）确认：

```powershell
python --version
```

能显示版本号（如 `Python 3.12.4`）就说明装好了。

## 二、启动后端

先进入项目目录（把下面路径换成你实际的目录）：

```powershell
cd 项目目录\campus-chat-backend
```

然后安装依赖（第一次需要，约 1~2 分钟）：

```powershell
pip install -r requirements.txt
```

启动服务：

```powershell
python run.py
```

看到这一行就说明成功了：

```
Uvicorn running on http://127.0.0.1:8000
```

> 补充：如果更想用虚拟环境（避免污染系统 Python），可改成：
> ```powershell
> python -m venv venv
> venv\Scripts\activate
> pip install -r requirements.txt
> python run.py
> ```

## 三、验证是否成功

浏览器打开：**http://127.0.0.1:8000/docs**

能看到中文的接口文档页面，就说明后端跑起来了。

## 四、小程序里怎么连这个后端

1. 后端地址就是：`http://127.0.0.1:8000`
2. 微信开发者工具里必须勾选「**不校验合法域名**」：
   - 右上角「详情」→「本地设置」→ 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」
3. 之后小程序里用 `wx.request({ url: "http://127.0.0.1:8000/api/..." })` 调用即可。

## 五、接口一览

### 认证 `/api/auth`
| 方法 | 路径 | 说明 | 是否需要登录 |
| --- | --- | --- | --- |
| POST | `/api/auth/register` | 注册，返回 token | 否 |
| POST | `/api/auth/login` | 登录，返回 token | 否 |
| GET | `/api/auth/me` | 当前用户信息 | 是 |

### 好友 `/api/friends`
| 方法 | 路径 | 说明 | 是否需要登录 |
| --- | --- | --- | --- |
| GET | `/api/friends` | 好友列表 | 是 |
| POST | `/api/friends/request` | 发送好友申请 | 是 |
| GET | `/api/friends/requests` | 收到的好友申请 | 是 |
| POST | `/api/friends/requests/{id}/accept` | 同意申请 | 是 |
| POST | `/api/friends/requests/{id}/reject` | 拒绝申请 | 是 |
| DELETE | `/api/friends/{friend_id}` | 删除好友 | 是 |

### 消息 `/api/messages`
| 方法 | 路径 | 说明 | 是否需要登录 |
| --- | --- | --- | --- |
| POST | `/api/messages` | 发送消息 | 是 |
| GET | `/api/messages/{friend_id}` | 聊天记录 | 是 |

### 实时聊天 WebSocket
- 地址：`ws://127.0.0.1:8000/ws?token=<你的token>`
- 小程序里用 `wx.connectSocket` 连接。

## 六、常见问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `'uvicorn' 不是内部或外部命令` | 依赖没装上 | 重新执行 `pip install -r requirements.txt` |
| `Address already in use` / 端口被占用 | 8000 端口被占 | 改端口：`python run.py` 里改成 `port=8001`，或用 `uvicorn app.main:app --port 8001` |
| 网页打不开 | 服务没启动 | 确认终端里那行 `Uvicorn running` 还在，且终端窗口没关 |
| 小程序请求失败 | 没勾选「不校验合法域名」 | 按第四节第 2 条勾选 |
