# 校园安全聊天微信小程序（国密 SM2 / SM3 / SM4 体系）

本项目是一个专为校园通信打造的**国密安全聊天小程序系统**，由 **FastAPI 后端** 和 **原生微信小程序** 两部分组成。
系统核心特色：全面采用国家密码管理局规范的 **商用密码算法体系（SM2、SM3、SM4）** 保护通信全流程，**实现服务器数据库聊天记录“零明文存储”**，杜绝拖库泄密风险与数据伪造篡改。

---

## 🌟 核心特色与国密防护架构

| 国密算法 | 密码标准 | 在系统中的核心作用 |
| :--- | :--- | :--- |
| **SM2** | GB/T 32918 | **非对称公钥密码**（256-bit 椭圆曲线）。为每位注册学生生成公私钥对；在建立好友时，利用双方公钥加密分发 SM4 对称会话密钥（数字信封机制）；同时服务器私钥用于对登录 Token 签名防伪造。 |
| **SM3** | GB/T 32905 | **密码杂凑算法**（256-bit 摘要值）。替代 MD5/SHA-1，用于用户登录密码加盐哈希存储；每条聊天消息附带明文 SM3 摘要值，接收方读取时校验一致性，提供端到端防篡改能力。 |
| **SM4** | GB/T 32907 | **分组对称密码**（128-bit，CBC 模式 + 随机 IV）。用于消息正文加解密。**服务器数据库只保存 16 进制密文 (ciphertext) 与初始向量 (iv)，不存任何明文**，彻底解决服务器明文泄露隐患。 |

## 📱 小程序页面矩阵（完整 6 大页面）

1. **登录注册页 (`pages/auth/index`)**
   - 支持账号密码登录与新用户注册（设置校园昵称与学号/用户名）。
   - 注册时自动派生专属 SM2 椭圆曲线公私钥，密码经 SM3 加盐存储。
   - 提供快速测试账号一键填充（Alice / Bob）。
   - 提供后端服务器地址配置面板（默认 `http://127.0.0.1:8000`，支持真机局域网 IP 切换）。
   - 已登录状态检测与退出登录。

2. **消息首页 (`pages/index/index`)**
   - 实时信道加密在线状态指示条（WebSocket 握手）。
   - 最近会话列表：展示好友头像、昵称、解密后的最后一条消息预览、时间、SM4 保护标签。
   - 收到好友添加申请时顶部小红点提示条。
   - 点击会话一键进入聊天。

3. **好友页面 (`pages/friends/friends`)**
   - 顶部搜索框：支持根据学号、用户名或昵称搜索全校已注册同学。
   - 智能关系识别：已是好友、待通过申请、已发送申请或可添加。
   - 收到的好友申请列表：支持一键同意或拒绝。同意申请时自动生成 128 位 SM4 会话密钥并由双方 SM2 公钥加密存库。
   - 好友通讯录列表：长按或点击可唤出操作菜单（发消息、复制学号、解除好友）。

4. **聊天页面 (`pages/chat/chat`)**
   - 实时加密通信：优先基于 WebSocket 实时收发，支持断线重连与 REST 自动降级。
   - 消息气泡流：展示发送者与接收者气泡，附带“🛡️ SM3验真”安全徽章。
   - **国密加密凭证抽屉 (Crypto Proof Modal)**：点击任意一条消息，即可查看该消息在服务器数据库中真实保存的 **SM4-CBC 密文十六进制**、**16 字节随机初始向量 IV**、**SM3 完整性哈希** 及验真结果，极具答辩说服力！

5. **安全中心 (`pages/security/security`)**
   - 查看当前登录用户的国密数字身份卡片与安全等级。
   - 密码防护核心指标统计：SM4 加密会话数、密文存储消息数、**数据库明文暴露 0 条**、SM3 校验通过率 100%。
   - 密钥状态面板：展示当前用户 SM2 公钥（支持一键复制 128 位公钥 Hex）、私钥托管隔离状态、活跃会话密钥对。
   - 国密三剑客规范深度解析与《商用密码应用安全性评估规范》合规说明。
   - 退出当前登录账号。

6. **加密演示页 (`pages/demo/demo`)**
   - 国密全流程可视化沙箱实验台，专供演示、评委答辩与技术检验。
   - 支持自由输入任意测试明文，提供典型校园测试用例快捷填入。
   - 支持双演算引擎：“后端商密沙箱引擎”与“小程序前端纯 JS 离线引擎”。
   - 分步动态演算呈现：
     - Step 1: SM3 密码杂凑（256 位哈希摘要与雪崩效应）
     - Step 2: SM4 对称加密（128 位随机密钥、随机 IV、密文十六进制）
     - Step 3 & 4: SM2 密钥信封（公钥加密会话密钥、私钥还原密钥）
     - Step 5 & 6: SM4 解密与明文还原、SM3 完整性比对验真
     - Step 7: **恶意篡改攻击防御模拟**（翻转密文字节，触发 SM3 校验失败告警，直观展示国密防篡改威力）。

## 🚀 启动与使用指南

### 1. 启动后端服务

后端使用 Python 3.10+，FastAPI 框架：

```bash
# 1. 进入 backend 目录
cd backend

# 2. 安装依赖（已在环境中就绪）
pip install -r requirements.txt

# 3. 运行后端服务
python run.py
```

- 后端 API 地址：`http://127.0.0.1:8000`
- 中文 API 文档：`http://127.0.0.1:8000/docs`
- 实时 WebSocket 地址：`ws://127.0.0.1:8000/ws?token=<token>`

### 2. 导入微信开发者工具运行小程序

1. 打开 **微信开发者工具**（WeChat DevTools）。
2. 点击 **“导入”** 项目。
3. 目录选择本项目中的 **`miniprogram`** 文件夹。
4. AppID 可以选择自己的测试号或个人 AppID。
5. 在微信开发者工具右上角 **“详情” -> “本地设置”** 中勾选：
   - ✅ **不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书**
6. 点击编译，即可在模拟器中完整体验！

### 3. 真机调试或局域网预览（可选）

如果要用手机微信扫码真机预览：
1. 确保电脑与手机在同一 Wi-Fi 局域网下。
2. 查看电脑局域网 IP（例如 `192.168.1.100`）。
3. 启动后端时 `host="0.0.0.0"`（`run.py` 默认已配置监听 `0.0.0.0`）。
4. 在小程序的 **登录页底部的“服务器地址配置”** 中，将地址修改为 `http://192.168.1.100:8000` 并保存即可！
